# Setup guide

## Learning package

This package is portable Markdown and JSON. Open it in any text editor or Markdown viewer.

## Optional source inspection

1. Work on a copy or isolated checkout of the source repository.
2. Read its README and files listed under configuration/dependencies before installing anything.
3. Use an isolated environment appropriate to the declared stack. Do not assume package versions are current or compatible.
4. Review environment examples; provide only locally scoped credentials if a provider is explicitly required.
5. Run only commands documented by the source project after reviewing their effects.
6. Record exact commands, versions, outputs, and failures. This educational package did not execute them.

### Evidence available

- `.github/workflows/ci.yml`
- `go.mod`

Do not publish secrets, datasets, databases, or generated artifacts. Deployment is not covered as a verified outcome.
