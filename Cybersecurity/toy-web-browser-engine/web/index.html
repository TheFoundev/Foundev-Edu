From bytes to boxes, in one readable pipeline.

A small browser engine in Rust: an HTML tokenizer, DOM tree builder, HTML serializer, CSS parser and cascade with selector matching, a box-model layout engine and an HTTP fetcher.

Open the console How it works
This is a Rust library and CLI, not a hosted product. It is part of the Foundev portfolio: a self-contained repository with its own tests and README. The page you are reading is a project console — the numbers below are computed from the repository, and the demo runs the project's own command.
What it does

The capabilities

Every panel below is served by the console's real API — nothing here is a mock-up.

⌗

A real HTML tokenizer

Tags, attributes, text, comments, doctypes and self-closing tags, with entity decoding.

◫

A DOM and serializer

Void elements, implicit end tags and stray end tags are handled, and the document round-trips.

◈

CSS and the cascade

Rules, declarations, selector lists, specificity, inheritance and descendant combinators.

▦

Box-model layout

Content, padding, border and margin for content-box and border-box, with percentage widths.

⇩

HTTP fetching

Relative links and assets are resolved and fetched with a blocking client.

✓

34 tests

Unit and integration tests cover every stage of the pipeline.

Architecture

How it works

The pipeline mirrors a real engine in a size you can read: HTML text to tokens, tokens to a DOM, DOM to computed styles, computed styles to layout boxes. CSS parsing and matching are separate from layout. Fetching is the only stage that touches the network; the rest is pure and heavily tested.
