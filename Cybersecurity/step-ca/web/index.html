Issue the leaf, verify the chain.

A tiny certificate authority: an ECDSA root and intermediate, CSR-based leaf issuance with SAN and validity, chain verification, and PEM output for the CA and the issued certificate.

Open the console How it works
This is a Go CLI, not a hosted product. It is part of the Foundev portfolio: a self-contained repository with its own tests and README. The page you are reading is a project console — the numbers below are computed from the repository, and the demo runs the project's own command.
What it does

The capabilities

Every panel below is served by the console's real API — nothing here is a mock-up.

⚿

ECDSA root and intermediate

The trust chain is generated with crypto/x509, root signing intermediate signing leaf.

◈

CSR-based issuance

A leaf is issued from a certificate signing request with the requested SAN and lifetime.

✓

Chain verification

The issued certificate is verified back to the root before it is written.

⇩

PEM in and out

The CA and the leaf are written as PEM files that other tools can consume.

⌗

One small binary

The whole flow is a Go CLI with no external service.

Architecture

How it works

pki.go implements the CA: generate the root and intermediate, parse a CSR, sign the leaf and verify the result. main.go is the CLI that wires the flags to the PKI and writes the artefacts. There is no ACME server, provisioner database or revocation in this build, and the README says so rather than implying production readiness.
