# Glossary

## Feature

A measurable input value supplied to an algorithm.

## Label

The target category/value a supervised model learns to predict.

## Inference

Using an already configured model or algorithm to produce an output.

## Threshold

A cutoff that turns a score into a category or action.

## Leakage

Information from outside the permitted training period/split that makes evaluation unrealistically easy.

## Baseline

A simple comparison method that helps reveal whether a complex method adds value.

## Artifact

A file such as a checkpoint, dataset, or index that the program needs at runtime.

## Human Review

A qualified person checks context and corrects or rejects an automated suggestion.
