Listen for the phrase, not the noise.

An always-listening wake-word recogniser built from synthetic positives and negative background clips: log-band audio features, a random-forest detector, and accuracy plus false-positive rate.

Architecture

How it works

src/ generates the clips, extracts log-band features and trains the classifier. main.py exposes train and demo; the demo prints the accuracy and false-positive rate on held-out clips. The CSV stack names the Google Speech Commands dataset and quantisation; that dataset and those models are not available offline, so the build generates its own clips, as the README records.
