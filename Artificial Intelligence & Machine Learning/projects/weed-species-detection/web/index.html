Which species is this leaf?

Classify synthetic weed species from leaf features: procedurally drawn leaves, shape and colour summary features, a random forest with per-species accuracy, and sample images saved for inspection.

Open the console How it works
This is a Python model, not a hosted product. It is part of the Foundev portfolio: a self-contained repository with its own tests and README. The page you are reading is a project console — the numbers below are computed from the repository, and the demo runs the project's own command.

Architecture

How it works

src/ draws the leaves, extracts the features and trains the model. main.py exposes train and demo; the demo prints the per-species accuracy and writes sample images. The CSV stack names ResNet50 and InceptionV3 transfer learning; pretrained ImageNet weights are not available offline, so the build uses hand-built features and a random forest, as the README records.
