Hear the phonemes, decode the word.

A low-resource ASR workflow: synthetic words made from phoneme-like tone segments, frame features and frame-level labels, a frame classifier, greedy collapse decoding and word error rate.

The capabilities

Every panel below is served by the console's real API — nothing here is a mock-up.

◫

Synthetic words

Words are built from phoneme-like tone segments, so no corpus download is needed.

⌗

Frame-level supervision

Features and labels are aligned at the frame level.

◈

A frame classifier

A random forest predicts the phoneme class for each frame.

⇄

Greedy collapse

Repeated frames collapse to a phoneme sequence and then to words.

✓

Word error rate

The demo reports WER, not just frame accuracy.

Architecture

How it works

src/ synthesises the audio-like segments, extracts frame features and trains the per-frame classifier. Decoding collapses repeats and maps the phoneme sequence to words. main.py exposes train and demo. The CSV stack names Wav2Vec2 fine-tuning; pretrained weights are not available offline, so this build uses frame-level features and a small classifier for the same pipeline, as the README records.
