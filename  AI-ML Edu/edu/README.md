# AI/ML 36-Project Learning Library

This is a new, separate library for the 36 source projects in `/home/aziz/foundev/AI-ML`. It is kept separate from the earlier 20-project AI/ML library. Each package maps its lessons and code excerpts to the actual source files; project READMEs document deliberate simplifications and missing production features.

- `projects/` — 36 standalone learning packages
- `dist/` — one ZIP per project
- `schemas/` — shared package schemas
- `tools/` — reproducible builder and structural/source-focus validator
- `reports/module-source-audit.md` — every module's source files and code focus
- `reports/source-review.md` — source limitations requiring human review

Each module starts with a plain-language explanation before moving to a cited source-code excerpt. The code examples are excerpts from the supplied repositories and were not executed by the generator.
