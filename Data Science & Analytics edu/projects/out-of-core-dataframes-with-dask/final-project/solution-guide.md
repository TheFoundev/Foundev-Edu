# Mentor solution guide

A strong solution begins by narrowing a README claim to a concrete code path. Require learners to name exact source locations, caller/callee relationships and a test or explain why no test exists. Review the change for compatibility, input validation, privacy and failure handling.

Accept more than one implementation. Do not award credit for invented runtime outcomes. Verify any submitted patch in an isolated environment before discussing execution results; this package did not run the project.
