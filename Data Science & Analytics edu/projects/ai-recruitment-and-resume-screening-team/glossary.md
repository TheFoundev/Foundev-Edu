# Glossary

- **Entry point:** File or command that begins a program's execution.
- **Data lineage:** The path data takes through inputs, transformations, and outputs.
- **Dependency:** A package or service needed by some code path.
- **Configuration:** Values that change behavior without changing the main source logic.
- **Test evidence:** A recorded assertion or execution result; merely having a test file is not a passing result.
- **Source of truth:** For what code does, implementation/configuration outranks descriptive documentation.
- **Proposed extension:** A learner-designed change that is not represented as an existing feature.
