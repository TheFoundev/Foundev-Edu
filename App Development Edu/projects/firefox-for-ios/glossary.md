# Glossary — Firefox for iOS

- **application state:** Values that currently drive the interface or domain model.
- **adapter:** A boundary that lets callers use one contract with different implementations.
- **fixture:** A controlled sample value used by a test or demo.
- **integration test:** A check spanning connected parts; it does not necessarily cover a real external service.
- **persistence:** Saving and restoring data after a process or app restart.
- **source of truth:** The authoritative owner for a value or behavior.
- **simulation:** Code that imitates an external process without contacting or representing that real service.
- **protection level:** A demo setting selecting a sample set of content rules.
- **WebKit:** Apple’s web content engine; this project does not embed Gecko.
