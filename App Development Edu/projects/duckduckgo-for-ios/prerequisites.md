# Prerequisites — DuckDuckGo for iOS

## Recommended background

- Introductory programming, functions, collections, and basic debugging.
- Git and command-line basics.
- Familiarity with Swift and declarative UI; the lessons explain project-specific concepts from the ground up.
- A machine that supports the platform required by the project. The JavaScript apps use Node.js/npm and Expo; SwiftUI apps require macOS, Xcode, and an iOS simulator or device.

## Before beginning

1. Read the app's own `README.md` in the adjacent `../../../projects/duckduckgo-for-ios/` source copy.
2. Review [setup-guide.md](setup-guide.md), project safety limits, and local test commands.
3. Do not add real credentials or real personal, financial, health, or cryptocurrency data.

## Expected starting point

You should be able to open the source tree, locate a named function or view, make a small local edit, and explain what evidence a unit test provides. Platform builds and external integrations are reviewed separately and are not assumed to work.
